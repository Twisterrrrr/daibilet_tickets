# Venue page — блок «Программа площадки» (выставки)

## Назначение

Показать на странице площадки не общий список карточек каталога, а **программу во времени**: что идёт сейчас, что откроется позже, архив прошедших. Данные — из тех же `Event`, что и каталог, с подкатегорией выставки и привязкой к `venueId`.

## Секции и порядок

1. **Сейчас проходит** (`current`)
2. **Скоро откроются** (`upcoming`)
3. **Прошедшие** (`past`) — по умолчанию свёрнуто (accordion)

## Лимиты первого экрана

| Зона | Лимит | Поведение при превышении |
|------|--------|---------------------------|
| Текущие — hero | 1 | Первая по сортировке (с учётом featured) |
| Текущие — secondary | до 3 видимых | Кнопка «Показать все выставки площадки» |
| Будущие | до 3 | Та же CTA при большем количестве |
| Прошедшие | 6–8 после раскрытия | «Показать ещё» при необходимости |

## Пустые и ошибочные состояния

- Нет `current` и `upcoming`: компактный empty-state («Сейчас нет активных выставок»); если есть `past` — акцент на раскрытие архива.
- Ошибка API программы: страница площадки не падает; блок программы скрыт или показывается краткое сообщение.

## Классификация по времени (read-model)

См. backend: окно `[startsAt, endsAt]` вычисляется из `dateMode`, сеансов и `endDate` / `isPermanent`. Состояние элемента: `CURRENT` | `UPCOMING` | `PAST`.

## Техдолг

- `VenueDetail.exhibitions` по-прежнему отражает все события площадки для вспомогательных флагов (например open-date для билетного блока), не для отображения программы выставок.
- Невыставочные OPEN_DATE-события могут влиять на билетный блок, но не попадают в программу выставок.
