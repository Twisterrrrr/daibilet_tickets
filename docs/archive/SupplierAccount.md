# Supplier Account (ЛК поставщика) — статус финансовых расчётов

> Виджет статуса финансовых настроек. Read‑only для поставщика, full‑control только в админке.

---

## 1. Виджет «Статус финансовых расчётов»

- **Цель:** прозрачно показать поставщику, как именно сейчас идут деньги и фискализация, не давая при этом возможности сломать налоговый контур платформы.
- **Расположение в ЛК:**
  - либо на `Dashboard` (блок «Финансы»),
  - либо во вкладке `Settings → Финансы`.

### 1.1 Логика отображения (mapping paymentMode → текст)

- Если `paymentMode = SINGLE_MERCHANT`:
  - Текст: **«Прямые выплаты от платформы»**.
  - Подпись: деньги поступают на счёт Daibilet, фискализация чеков идёт от имени платформы.
- Если `paymentMode = AGENT_SINGLE_PAYOUT`:
  - Текст: **«Агентская схема (фискализация на стороне платформы)»**.
  - Подпись: Daibilet выступает агентом, реквизиты поставщика используются как принципала в чеке.
- Если `paymentMode = SPLIT_MERCHANT`:
  - Текст: **«Автоматический сплит платежей (YooKassa)»**.
  - Подпись: платежи делятся между платформой и поставщиком средствами эквайера.

Во всех режимах под текстом показывается короткое пояснение и дата последнего изменения настроек (по данным `OperatorPaymentSettings`).

### 1.2 Управление и права

- Виджет **read‑only**: поставщик видит, но не может редактировать:
  - `paymentMode`,
  - признак агентской схемы,
  - информацию о split.
- Кнопка **«Изменить схему выплат»**:
  - ведёт не в форму настроек, а в создание тикета поддержки / ссылку «Написать в поддержку»;
  - текст подчёркивает, что изменения финансовых настроек выполняются только через админку Daibilet.

### 1.3 Технический контракт (API)

- `GET /supplier/finance/settings` → облегчённый объект:
  - `paymentMode`,
  - `agentSchemeEnabled`,
  - `splitEnabled`,
  - `updatedAt` (последнее изменение настроек),
  - опционально: человекочитаемый summary, чтобы фронт мог только рендерить.
- Настройки берутся из `OperatorPaymentSettings` (1–1 к `Operator`), которые редактируются через admin‑API:
  - `GET /admin/operators/:id/payment-settings` — полный объект для админки.
  - `PATCH /admin/operators/:id/payment-settings` — только для ролей ADMIN / SUPERUSER.
