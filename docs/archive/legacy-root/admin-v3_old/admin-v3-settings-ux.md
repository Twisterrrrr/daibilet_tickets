## 4. Детали по разделам

### 4.1 Синхронизация и операции

- Статус: те же поля, что V1; при `lastError` — заметное предупреждение.
- Кнопки: подписи на русском или как в API (как договоримся в UI-копирайте); loading — per-action.
- Flush cache: сохранить выбор namespace; destructive-стиль кнопки.

### 4.2 Цены

- Сохранение одним действием; после сохранения — обновление локального состояния из ответа (как V1).

### 4.3 Пользователи

- Таблица: email, имя, роль, активность, последний вход — как минимум паритет с V1.
- Ограничения по редактированию — по политике бэкенда; в UI не показывать недоступные контролы или disabled с подсказкой.

## 5. Связь с технической реализацией (без смены контрактов)
