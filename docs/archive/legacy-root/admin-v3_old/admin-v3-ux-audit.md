- Минусы: **нет клавиатурного эквивалента** для «клик по пустоте»; для скринридеров область «кликабельного пустого header» неочевидна; на таче случайные нажатия по шапке возможны.

**Рекомендация:** убрать клик с `header` и оставить только явную кнопку «свернуть шапку»; либо отдельная кнопка «Развернуть» в свернутом режиме без клика по всей полосе.

### 3. Таблицы

- Паттерн `overflow-x-auto` + большой `min-w` — **соответствует** «не сжимать таблицу в крошки».
- Нет **визуальной подсказки** «контент продолжается» (fade/shadow на краю) — из гайдлайна §9.

**Рекендация:** опционально обернуть общий скролл-контейнер (например расширение `DataTableShell` или общий `TableScrollRegion`).

### 4. Загрузка

`LoadingState`: короткий текст + 2 полоски pulse — не **skeleton** под структуру страницы.

**Рекомендация:** для тяжёлых списков — skeleton строк/карточек; для форм — скелет полей (по мере появления страниц с длинным TTFB).

### 5. Иерархия CTA

На детальных экранах (`CollectionDetailPage`, `LandingDetailPage`, `EventDetailPage`) часто рядом **несколько** кнопок уровня primary (`default`) или конкурирующие «Сохранить» / «Опубликовать».

**Рекомендация:** явно назначать **одну** primary на блок; остальное — `secondary` / `outline` (уже частично так, но не везде).

### 6. Мелкий текст и контраст

- В таблицах часто `text-xs` для заголовков колонок и ячеек — для **вторичной** информации допустимо; следить, чтобы `text-muted-foreground` не использовался для длинного чтения body.
- Бейдж инбокса в сайдбаре: `text-[10px]` — ок для счётчика, не для основного текста.

### 7. Поля без видимого label (кроме placeholder)

- `SettingsPage` (SEO): подписи как `text-xs text-muted-foreground` над полем — **labels есть**, но визуально слабее; для ключей вроде `siteName` можно усилить читаемость.
- `FeatureFlagsPanel`: колонка Description — `Input` без отдельного `<label>`, есть placeholder — **слабее** гайдлайна §4.

### 8. Оптимистичный UI

- Feature flags: локальный draft — ок.
- Мутации списков (одобрение отзыва, рефанд): состояние через `disabled` на кнопках, без оптимистичного обновления строк — **нормально** для финансово-чувствительных действий.

### 9. 8pt grid

В разметке много Tailwind-отступов `gap-2`, `gap-3`, `p-5`, `py-1.5` — часть из них **не кратна 8** в px (из-за шкалы Tailwind). Это **не баг**, но при жёстком аудите гайдлайна — отметить как «смешанная шкала проекта (4/8)».

## Приоритетный бэклог (предложение)

| Приоритет | Действие |
|-----------|----------|
| P1 | Topbar: убрать или переработать клик по всей шапке; явное управление сворачиванием |
| P1 | Политика размеров кнопок: либо touch-friendly breakpoint, либо зафиксированное исключение в гайдлайне |
| P2 | Общий scroll-hint для широких таблиц |
| P2 | Skeleton для «тяжёлых» первых загрузок списков |
| P3 | Пройтись по экранам с 2+ primary и выровнять варианты |
| P3 | Добавить явные `<label>` для полей в таблице feature flags (колонка Description) |
