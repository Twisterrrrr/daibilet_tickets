# Process — как вести документацию

## Дневник решений

- Основной дневник: [`Diary.md`](Diary.md)
- Правило: каждая запись содержит **дату** и секции **«Наблюдения / Решения / Проблемы»**.
- Дневник — источник контекста “почему так”, но не заменяет core‑документы. Если решение стало инвариантом — оно должно быть отражено в `Project.md` / `Operations.md` / соответствующем core‑документе.
