# Ingestion (Imports) — core

Этот файл — **точка сборки** по импорту/синкам и ограничениям маппинга.

## Текущее состояние

- Подробные исторические материалы и чеклисты по интеграциям временно лежат в `archive/integrations/legacy-folders-integrations/`.

## Инварианты (MVP)

- Импорт = внешний слой данных; локальные override’ы не должны стираться синком.
- Внешние идентификаторы и статусы — отдельный слой, не смешивается с внутренним жизненным циклом.
- Любая новая интеграция должна иметь явные mapping constraints (event/session/venue) и безопасную деградацию.
