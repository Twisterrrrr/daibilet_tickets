# Landing Reference Pages

## Purpose

These routes are the **UX reference set** for public landing pages.

They define the desired landing behavior, pacing, composition, and section rhythm.

Treat them as the reference model for public destination/category/event SEO landings.

---

## Reference routes (Lovable)

**Base:**

- `https://night-bridges.lovable.app/`

**Category / vertical:**

- `https://night-bridges.lovable.app/bus-tours`
- `https://night-bridges.lovable.app/bus-tours/{city}`
- `https://night-bridges.lovable.app/river-cruises/`
- `https://night-bridges.lovable.app/river-cruises/{city}`

**Seasonal / campaign:**

- `https://night-bridges.lovable.app/salute-9-may`
- `https://night-bridges.lovable.app/salute-9-may/{city}`

**Event / offer detail style:**

- `https://night-bridges.lovable.app/events/dinner-cruise/moscow`

---

## Interpretation rule

Even if exact content differs by route, these pages together define the desired UX family:

- destination-like landings
- category-like landings
- city-variant landings
- campaign/seasonal landings
- event-offer landing pages

---

## Product rule

These are **not** admin pages.

These are **not** generic catalog indexes.

These are **not** plain search results.

These are **editorial / promotional / SEO-oriented** landing pages.

---

## Allowed adaptation for Daibilet

The only default adaptation:

- add Daibilet global header
- add Daibilet global footer

Everything else should preserve reference UX principles unless a task explicitly says otherwise.

---

## Absolute rule

Do not downgrade these pages into standard site templates.
